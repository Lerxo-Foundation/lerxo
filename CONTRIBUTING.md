# Contributing to Lerxo

Thank you for your interest in Lerxo.
Lerxo is currently in the early stages of development. The project is being built from first principles, and its architecture and development practices are still evolving.

## Before Contributing

Please read:

* `README.md`
* `ROADMAP.md`
* `SECURITY.md`
* `docs/ARCHITECTURE.md`

These documents describe the project's goals, planned development, security principles, and architectural direction.

## Development

Lerxo is written primarily in Rust.
Contributions should:

* Follow the existing project structure
* Prefer clear and maintainable code
* Include appropriate documentation
* Avoid unnecessary dependencies
* Consider security and reliability implications
* Keep changes focused and reviewable

## Issues

Issues may be opened for:

* Bug reports
* Feature proposals
* Documentation improvements
* Architectural discussions
* Development tooling

Please provide enough information for the issue to be understood and reproduced.

## Pull Requests

Pull requests should explain:

1. What has changed
2. Why the change is necessary
3. How the change has been tested
4. Any known limitations or future work

Large architectural changes should be discussed before implementation where practical.

## Security

Please do not publicly disclose security vulnerabilities through ordinary issues.
See `SECURITY.md` for security-related guidance.

## Current Contribution Status

Lerxo is currently undergoing foundational development.

The project may limit external contributions while its core architecture is established. Contribution requirements and review procedures will become more formal as the project matures.
