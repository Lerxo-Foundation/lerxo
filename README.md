# Lerxo

**A modern operating system built from scratch in Rust.**

Lerxo is an experimental general-purpose operating system designed with a focus on security, performance, reliability, and simplicity.

## Vision

Lerxo aims to provide a modern computing environment built from first principles, with a coherent architecture and carefully designed system interfaces.

## Principles

* **Rust-first** — memory safety wherever practical
* **Secure by design** — isolation and least privilege as fundamental principles
* **Reliable** — predictable behaviour and robust system components
* **Efficient** — careful use of system resources
* **Understandable** — clear architecture and maintainable code
* **Modular** — well-defined components and interfaces

## Development Status

**Pre-alpha — development has begun.**

Lerxo is currently under active development and is not intended for production use.

## Initial Target

The first development target is a bootable x86-64 system running safely inside a virtual machine.

Physical hardware support will be introduced as the project matures.

## Planned Features

* Rust kernel
* UEFI boot
* x86-64 support
* Memory management
* Multitasking
* Processes and threads
* Inter-process communication
* Filesystem
* Networking
* Security and capability system
* Graphics subsystem
* Desktop environment
* Package management

## Architecture

Lerxo is being designed from first principles rather than around compatibility with an existing operating-system kernel.

Further architectural documentation will be published as development progresses.
